# PROTOCOLO · nuevo chat / nuevo agente

## Primeros 15 minutos

1. **Quién soy**
   - alias;
   - número histórico;
   - puesto;
   - jefatura;
   - límites.

2. **Qué sé**
   - leer último APRENDIZAJE;
   - identificar lagunas;
   - NO asumir que otro chat compartió conocimiento implícito.

3. **Formación**
   - revisar plan de profesión;
   - estudiar fuentes necesarias para lagunas críticas;
   - resumir con palabras propias.

4. **Proyecto**
   - HEAD coordinación vivo;
   - Estado actual;
   - Control;
   - Memoria relevante;
   - Orden vigente;
   - issue/PR;
   - normativa aplicable.

5. **Sistemas vivos**
   Si toca web:
   - HEAD A2;
   - PR;
   - workflows;
   - Deploy Preview/Netlify;
   - build candidate.

   Si toca Cloud:
   - versión/deploy real;
   - manifest;
   - acceso;
   - contratos.

   Si toca Social:
   - cola real;
   - plataformas;
   - estado de cuentas;
   - herramientas disponibles.

6. **RESUME GATE**
   Comparar con último SHA/estado conocido.

7. **Prueba mínima**
   Reproducir una operación segura antes de modificar:
   - build;
   - test;
   - lectura de deploy;
   - consulta de analítica;
   - etc.

## Prohibido

- continuar solo desde memoria del chat;
- decir “ya sé el proyecto” sin revalidar;
- usar formación antigua como sustituto de HEAD vivo;
- pedir a María que resuelva una habilidad profesional que el agente debe aprender;
- declarar formación completa sin práctica.
