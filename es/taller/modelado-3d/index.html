El taller

Modelado 3D

Construye objetos juntando formas: cubos, esferas, cilindros, conos, pirámides, anillos y cuñas. Una forma puede ser sólida o un hueco que perfora a las demás. Todo se mide en milímetros, listo para imprimir en 3D.

Qué puedes crear aquí

  • Un llavero con tu inicial o un dibujo
  • Un soporte para el móvil
  • Una caja con tapa que encaja
  • Piezas de repuesto, maquetas y prototipos
  • Archivos STL para imprimir, GLB para la web y OBJ para otros programas

Cómo se usa

  1. Elige una forma en la barra y pulsa «Añadir sólido». Aparece sobre la cama de impresión.
  2. Toca una forma para elegirla. Con las flechas de colores del modelo la mueves; con «Girar» y «Escalar» cambias su giro y su tamaño. También puedes escribir las medidas en Propiedades.
  3. Para hacer un agujero, añade un hueco y colócalo donde quieras quitar material.
  4. Elige varias formas (Mayús + toque, o Mayús + clic en la lista) y pulsa «Agrupar»: los sólidos se unen y los huecos perforan.
  5. Revisa el apartado «Antes de imprimir» y exporta en Archivo: STL para la impresora, GLB para la web u OBJ.

Sólidos y huecos

Un sólido añade material. Un hueco lo quita. Al agrupar, el estudio une todos los sólidos y resta los huecos: así se hace el agujero de un llavero o el interior de una caja. El grupo se puede desagrupar para volver a cambiar las piezas.

Medidas y cama de impresión

La cuadrícula es una cama de impresión de 200 × 200 mm con líneas cada 10 mm. Las flechas del teclado mueven 1 mm (10 mm con Mayús). «Apoyar en la cama» baja la forma hasta que toca la base: lo que flota en el aire no se puede imprimir sin soportes.

Qué archivo elegir

STL es el formato de las impresoras 3D: solo guarda la forma, sin color, y aquí se exporta con el eje Z hacia arriba, como esperan los programas de impresión. GLB guarda forma y color y se abre en visores web y en programas 3D. OBJ es un formato de texto que casi cualquier programa entiende. Los huecos sueltos no se exportan.

Cómo funciona por dentro

El dibujo usa WebGPU cuando el navegador lo ofrece y, si no, WebGL 2, sin que tengas que hacer nada. Las uniones y restas de formas se calculan con geometría sólida constructiva (CSG). Solo se dibuja cuando algo cambia, para gastar menos batería.

Tu trabajo y tus archivos

Lo que haces se queda en esta pestaña del navegador. No se envía a ningún sitio y el taller no lo guarda en el navegador.

Para conservarlo, abre Archivo y pulsa «Guardar proyecto»: se descarga un archivo a tu dispositivo. Para seguir otro día, abre Archivo, pulsa «Abrir…» y elige ese archivo. Las exportaciones (imágenes, sonido, modelos 3D, juegos) también son archivos que descargas tú.
