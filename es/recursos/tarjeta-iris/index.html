Mi Tarjeta Iris

Una tarjeta con tres cosas sobre ti, para enseñar cuando explicarlo de viva voz se hace cuesta arriba: en una consulta, en una ventanilla, en el trabajo, en clase.

Esta tarjeta se guarda solo en esta pestaña para poder recuperarla al recargar. Este guardado no la envía fuera del dispositivo y no hace falta ninguna cuenta.

Escribe lo tuyo

No hace falta rellenarlo todo de una vez, ni usar las tres partes. Una sola frase ya sirve.

Ahora mismo hay un ejemplo escrito, para que veas cómo queda. Puedes escribir encima o borrarlo.
