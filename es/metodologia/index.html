Metodología

Cómo seleccionamos y presentamos la información de Iris Green.

Esta página explica los criterios que seguimos para preparar el contenido de la web.

La información tiene una finalidad informativa. No ofrece diagnósticos ni tratamientos personalizados.

Fuentes

Cada contenido debe indicar qué fuentes se han utilizado, su fecha y qué información respaldan.

También debe quedar claro a qué personas, situaciones o lugares se refiere la información.

Utilizamos distintos tipos de fuentes según el contenido:

  • Publicaciones científicas y guías para las explicaciones relacionadas con la salud.
  • Organismos responsables y documentos oficiales para ayudas y trámites.
  • Testimonios identificados para las experiencias en primera persona.

Investigación, experiencias y recursos prácticos

Una investigación, una experiencia personal y un recurso práctico aportan información diferente. Por eso se presentan de forma separada.

Un testimonio explica cómo vive una situación una persona concreta. No significa que todas las personas tengan la misma experiencia.

Una plantilla, una frase editable o un recurso para organizar una tarea ofrece una opción que puede resultar útil. No garantiza que funcione igual para todas las personas o situaciones.

Cuando incluimos cifras, indicamos a qué población corresponden, qué periodo se estudió y la información necesaria para entenderlas.

Las etiquetas A, B y C

Algunas fichas utilizan las letras A, B y C para indicar qué tipo de respaldo tiene la información:

  • A: guía clínica o revisión sistemática.
  • B: documento institucional o estudio individual.
  • C: propuesta práctica que no se presenta como resultado de una investigación.

Estas letras deben leerse junto con las fuentes y sus limitaciones.

Una sola letra no permite valorar toda la información de una ficha ni garantiza que una propuesta funcione para todas las personas.

Lenguaje y presentación

Utilizamos explicaciones directas, ejemplos concretos y términos respetuosos.

Mantenemos los nombres oficiales cuando son necesarios para identificar una condición, un recurso, una ayuda o un procedimiento.

Los resúmenes permiten encontrar primero la información principal.

Los ajustes de lectura permiten cambiar la presentación del texto. Estos ajustes no significan que un contenido haya sido validado como material de lectura fácil.

Autoría y correcciones

Iris Green es la responsable editorial del proyecto.

Cuando un libro u otro material incluye una colaboración, se indica en el apartado correspondiente.

Si encuentras un error o una referencia que necesita revisarse, escribe a informacion@irisgreen.eu.

Incluye el enlace de la página y, si es posible, el fragmento al que te refieres.
