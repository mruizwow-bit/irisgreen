Autonomía · práctica real

Tareas cotidianas, paso a paso

Aquí se practican tareas que pueden costar trabajo. No hay nota, tiempo límite ni una única forma correcta de aprender.

Elige una sola tarea. Puedes mirar los pasos, probar uno, parar y volver otro día. Si una secuencia no te sirve, cámbiala. La ayuda también forma parte de hacer una tarea.

    Mochila · preparación

    La mochila de mañana

    Marca lo que quieres revisar antes de salir. No hace falta llevar todo todos los días.

    Puedes hacer una foto de la mochila preparada o dejar una lista junto a la puerta. No existe una mochila universal.

    Adolescentes y adultos · salir de casa

    La puerta de salida

    Elige solo las comprobaciones que tengan sentido para tu salida de hoy.

    Una comprobación puede quedarse fija junto a la puerta. Otra puede cambiar según el día.

    Vida adulta · casa

    Poner una lavadora

    Ordena mentalmente estos pasos y úsalos como lista. La máquina, las prendas y el detergente pueden tener instrucciones distintas.

    1. Revisar bolsillos y etiquetas de las prendas cuando haga falta.
    2. Meter la ropa sin sobrecargar la máquina.
    3. Añadir el producto indicado para esa lavadora siguiendo su etiqueta.
    4. Elegir un programa adecuado para la ropa.
    5. Iniciar la lavadora.
    6. Cuando termine, sacar la ropa y tenderla o secarla como corresponda.

    Seguridad: no mezcles productos de limpieza. Si no conoces una máquina o un producto, sigue su etiqueta o pide ayuda antes de usarlo.
