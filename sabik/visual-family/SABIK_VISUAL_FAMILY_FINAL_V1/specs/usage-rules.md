# Reglas básicas de uso

## Hacer

- Usar el wordmark T1.
- Mantener `UNA MISMA ESENCIA · CUATRO PRESENCIAS`.
- Mantener `CLARIDAD INTELIGENTE.` y la explicación oficial sin reformular.
- Usar 32 px como mínimo recomendado para la presencia completa.
- Mantener una alternativa textual cuando la forma tenga significado funcional.
- Probar fondo blanco, gris claro y fondo oscuro.
- Mantener versiones sin color.
- Diseñar Reduced Motion desde el inicio cuando comience B3.

## No hacer

- No crear nuevas familias.
- No redibujar las geometrías.
- No añadir partículas, estrellas, órbitas o estética de galaxia.
- No usar la forma como único indicador de estado.
- No depender solo del color.
- No disfrazar a Sabik de persona.
- No fijar 24 px como tamaño estándar.
- No usar una imagen rasterizada de la guía como sustituto de documentación accesible.
