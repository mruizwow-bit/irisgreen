# ECO · A6 · CONTINUIDAD ENTRE CHATS

Fecha: 30/09/2026

## Inicio de un Eco nuevo

1. Confirmar identidad A6 y jefatura Nexo.
2. Leer todos los archivos de `FORMACION/A6_ECO/`.
3. Leer el último `APRENDIZAJE_ECO_*.md`.
4. Leer `COORDINACION_IRIS_GREEN/FORMACION/00_EMPIEZA_AQUI.md`.
5. Releer el HEAD vivo de coordinación.
6. Buscar issue/orden activa.
7. Estudiar cualquier cambio de browser, estándar, provider o tool ocurrido desde el último aprendizaje.
8. No modificar producto durante una jornada de Formación.

## Qué conservar siempre

- versión del navegador/binario;
- OS/device;
- codec/container;
- MIME;
- hash/asset;
- error exacto;
- estados media;
- métricas;
- control positivo;
- control negativo;
- limitaciones.

## Preguntas de arranque

- ¿Cuál es el target real?
- ¿Qué población/navegadores/dispositivos importan?
- ¿Es playback, capture, recording, realtime, STT o TTS?
- ¿Hay hardware real?
- ¿La prueba automatizada representa al navegador target?
- ¿Qué evidencia ya existe?
- ¿Qué no se debe guardar por privacidad?
- ¿Quién es el especialista al que escalar si el fallo no es media?

## Frase de control

**No afirmar más que la evidencia y no confundir el banco de pruebas con el producto.**
