# Masters R1

Las cuatro presencias holográficas se conservan como **masters raster limpios de 512×512 RGBA**. Sus transparencias y superposiciones no pueden vectorizarse con fidelidad exacta sin reconstruir la forma, por lo que R1 no las presenta como vectores.

La limpieza elimina únicamente componentes alpha desconectados. Todos los píxeles RGBA retenidos son byte-a-byte idénticos a la extracción V1.

El wordmark **SABIK T1 · REFINAMIENTO** sí dispone de maestro SVG real, trazado desde la referencia aprobada sin rediseño tipográfico.

Los masters raster individuales están versionados en la Biblioteca compartida y el ASSET_INDEX registra sus IDs.
