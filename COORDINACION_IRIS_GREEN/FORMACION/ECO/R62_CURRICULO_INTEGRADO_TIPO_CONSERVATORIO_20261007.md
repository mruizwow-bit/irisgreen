## Hallazgo
La formación de composición real no separa:
- oído;
- ritmo;
- armonía;
- contrapunto;
- análisis;
- teclado;
- diseño musical;
- composición.

Por tanto Eco amplía R61 con cinco ejes paralelos.

# EJE A · Ear Training
- audiación;
- sight-singing;
- dictado;
- memoria;
- función tonal;
- intervalos;
- rhythm hearing.

# EJE B · Time & Rhythm
- pulso;
- subdivisión;
- simple/compound meter;
- syncopation;
- pickup;
- displacement;
- phrase rhythm;
- silence.

# EJE C · Harmony & Counterpoint
- functional harmony;
- voice leading;
- melodic construction;
- species counterpoint;
- independent lines;
- tendency tones;
- cadences.

# EJE D · Analysis
Jerarquía:
`fragment → motive → subphrase → phrase → period/sentence → section → form`

Analizar:
- qué material regresa;
- qué cambia;
- qué se fragmenta;
- dónde está la cadencia;
- cómo se construye expectativa;
- cómo se alcanza cierre.

# EJE E · Musical Design / Composition
- idea;
- repetition;
- variation;
- contrast;
- proportion;
- tension;
- release;
- climax;
- return;
- closure.

## Regla
No estudiar estos ejes como materias desconectadas.

Cada ejercicio compositivo debe pasar por:
`HEAR → SING → WRITE → ANALYZE → REVISE → REMEMBER`
