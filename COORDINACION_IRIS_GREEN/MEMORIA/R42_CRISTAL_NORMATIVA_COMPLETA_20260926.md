# Memoria · estudio de cristal bajo normativa completa · 26/09/2026

María recuerda que cualquier decisión derivada del estudio de Liquid Glass/glassmorphism debe aplicar **toda la normativa Iris Green**, no solo accesibilidad visual o contraste.

El estudio se conserva como input técnico útil para:
- ubicación del cristal;
- opacidad;
- contraste;
- bordes de control;
- dark chrome;
- reducción de transparencia;
- fallback.

Pero no puede:
- crear excepciones a ES/EN;
- saltarse requisitos web/móvil;
- sustituir WCAG/ISO/EN/COGA;
- ignorar privacidad/minimización;
- ignorar etapas de vida;
- ignorar lenguaje claro;
- degradar accesibilidad cognitiva;
- omitir teclado/foco/forced-colors/reduced-motion;
- considerarse aprobado por contraste si HUMAN QA falla.

Estado: `R42_CRYSTAL_STUDY_SUBORDINATE_TO_FULL_NORMATIVE`.
