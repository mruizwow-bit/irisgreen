Everyday tasks, step by step

Practise tasks that can take a lot of effort. There is no score, time limit or single correct way to learn.

    Adult life · home

    Using a washing machine

    Use these as a checklist. Machines, clothes and detergents can have different instructions.

    1. Check pockets and clothing labels when needed.
    2. Put the clothes in without overloading the machine.
    3. Add the product specified for that machine, following its label.
    4. Choose a suitable programme for the clothes.
    5. Start the machine.
    6. When it finishes, remove the clothes and dry them as appropriate.

    Safety: do not mix cleaning products. If you do not know a machine or product, follow the label or ask for help before using it.
