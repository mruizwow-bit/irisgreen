## Decisión

No existe un renderer obligatorio.

Cada experiencia puede usar 2D rico, 2.5D, raster, Canvas, WebGL, WebGPU con fallback u otra técnica adecuada.

Lo obligatorio es el resultado:
- producto premium contemporáneo;
- materialidad;
- iluminación;
- profundidad;
- composición;
- atmósfera;
- microdetalle;
- identidad;
- responsive;
- accesibilidad;
- rendimiento.

## Benchmark móvil

La norma se revisa antes de cada ola visual/escala y como máximo cada 8 semanas mientras haya trabajo visual activo.
