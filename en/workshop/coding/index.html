The workshop · Studio 12

Coding studio

Program a turtle that draws. With blocks or by typing: both are the same program. Start with a square and work up to fractals.

  • Blocks and text
  • English or Spanish
  • Step by step
  • Loops, variables and functions
  • Recursion
  • 15 challenges on 6 levels
  • Full keyboard use

How it works

  1. Pick a challenge or start in free mode. The violet outline shows what to draw.
  2. Add blocks with the “+” buttons, or switch to “Text” and type the program.
  3. Press “Run”. With “Step by step” you see what each instruction does: the running block is highlighted.
  4. If something goes wrong, the message says which line and why.
  5. Save the program to a file or the drawing as a PNG.

The tool needs JavaScript. Here are all the challenges so you can do them on paper or with another tool.

Challenges

The challenges are grouped by level. You can start with any of them.

Level 1 · Sequences

  1. Square. Draw a square with sides of 100 steps. The violet outline shows you where.
  2. Staircase. A staircase of five 30-step stairs going up to the right.
  3. House. A 100-step square with a triangular roof on top, all three sides equal.

Level 2 · Loops

  1. Square in three blocks. The same square, now with three blocks at most.
  2. Five-pointed star. A five-pointed star with sides of 150, without lifting the pen.
  3. Dodecagon. A 12-sided polygon with sides of 40 steps.

Level 3 · Variables and decisions

  1. Square spiral. A 20-sided spiral: the first side is 10 and each side is 10 longer than the one before.
  2. The 7 times table. Print the 7 times table under “Output”: 7, 14, 21… up to 70. Just the results, one per line.
  3. Zap!. Print the numbers from 1 to 20, but instead of each multiple of 3 print zap!

Level 4 · Functions

  1. One function for every polygon. Make a function with two parameters, sides and size, and use it to draw a triangle, a square, a pentagon and a hexagon of 80, all from the same point.
  2. Flower of squares. Twelve 80-step squares, each turned 30 degrees round the same point.

Level 5 · Recursion

  1. Tree. A tree where each branch splits into two shorter branches, until they are very small. At least 31 branches.
  2. Koch snowflake. The level-3 Koch snowflake: a triangle with sides of 300 starting at (-150, 90) facing right, where each side splits into four pieces again and again.

Level 6 · No ceiling

  1. Generative art. A drawing that changes each time you run it: use random() and at least three colours. No outline: it is yours.
  2. Your own fractal. Invent a fractal: a function that calls itself and draws at least 300 lines. Put its name in “Title” and save it.

The language

It is the Workshop’s own language. It understands English and Spanish, so a program written in one language works in the other. The turtle starts in the middle, at (0, 0), facing up; the canvas runs from -300 to 300 in each direction.

  • forward 100 · back 50: move forwards or backwards
  • right 90 · left 90: turn, in degrees
  • repeat 4 { … }: repeat what is inside a number of times
  • while x < 100 { … }: repeat while something is true
  • if x > 5 { … } else { … }: choose depending on whether something is true
  • x = 10 · x = x + 1: store a number or some text in a variable
  • function name(a, b) { … } · name(3, 50): make your own instruction and use it
  • print x: show a value under “Output”
  • and · or · not · true · false: combine conditions
  • random(1, 6) · sqrt(x) · abs(x) · sin(x) · cos(x) · round(x): calculations (sin and cos in degrees)
  • Colours: blue, red, green, orange, violet, pink, yellow, grey, brown, black or a code such as "#1f5f8b". Other instructions: penup, pendown, width 5, goto(x, y), setheading 90, home, circle 50. To find out where it is: xcor(), ycor(), heading().

Your work and your files

What you make starts in this browser tab. It is not sent anywhere. If you want to keep it, you can explicitly save it on this device or download your project file.

To carry on another day, press “Save file”: a file with your project downloads to your device. To pick it up again, press “Open file” and choose it. If you close the tab with unsaved changes, the browser warns you.
