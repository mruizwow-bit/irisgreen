# VECTOR · continuidad entre chats

## Antes de cerrar

Crear:
`APRENDIZAJE_VECTOR_<FECHA>.md`.

Incluir obligatoriamente:
- A2 HEAD actual;
- PR #244 estado;
- issues activos;
- Netlify deploy/preview relevante;
- qué integración está a medias;
- conflictos conocidos;
- runbook usado;
- qué intentos fallaron;
- qué NO volver a probar;
- siguiente operación segura.

## Al abrir chat nuevo

No empezar integrando.

Primero:
1. leer esta Formación;
2. leer último Aprendizaje;
3. RESUME GATE;
4. revalidar A2/coord/PR/deploy;
5. comparar contra último SHA del aprendizaje;
6. solo entonces escribir.

## Regla de mentoría

Cada error nuevo que cueste tiempo y tenga valor general se convierte en:
- aprendizaje;
- test;
- checklist;
- o ejercicio de Formación.

No debe repetirse como conocimiento “solo en la cabeza del chat anterior”.
