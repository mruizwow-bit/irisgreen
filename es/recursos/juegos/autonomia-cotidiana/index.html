Autonomía · práctica real

Tareas cotidianas, paso a paso

Aquí puedes practicar tareas que pueden costar trabajo. No hay nota, tiempo límite ni una única forma correcta de aprender.

Elige una sola tarea. Puedes mirar los pasos, probar uno, parar y volver otro día. Si una secuencia no te sirve, cámbiala. Pedir ayuda también forma parte de hacer una tarea.

Cordones · coordinación y secuencia

Atarse los cordones

Esta actividad practica una forma común de hacer un lazo. No es el único método válido. Puedes practicar con el zapato fuera del pie si te resulta más fácil.

Coloca esta secuencia.

    Mochila · preparación

    La mochila de mañana

    Marca solo lo que tenga sentido para mañana. No hace falta llevar todo todos los días.

    Puedes hacer una foto de la mochila preparada o dejar una lista junto a la puerta. Cada persona y cada día pueden necesitar cosas distintas.

    Adolescentes y adultos · salir de casa

    La puerta de salida

    Elige únicamente las comprobaciones que tengan sentido para la salida de hoy.

    Una comprobación puede quedarse fija junto a la puerta. Otras pueden cambiar según el día.

    Vida adulta · casa

    Poner una lavadora

    Usa estos pasos como una lista orientativa. La máquina, las prendas y el producto de lavado pueden tener instrucciones distintas.

    1. Revisar bolsillos y etiquetas de las prendas cuando haga falta.
    2. Meter la ropa sin sobrecargar la máquina.
    3. Añadir el producto indicado para esa lavadora siguiendo su etiqueta.
    4. Elegir un programa adecuado para la ropa.
    5. Iniciar la lavadora.
    6. Cuando termine, sacar la ropa y secarla como corresponda.

    Seguridad: no mezcles productos de limpieza. Si no conoces una máquina o un producto, sigue su etiqueta o pide ayuda antes de usarlo.
