# Taller · Informe de procesos de dibujo · R03
Actualizado: 2026-10-10.

Informe de 51 páginas con secuencias ilustradas, objetivos, acciones y comprobaciones. Conserva las primeras 42 páginas y añade la secuencia reiniciada de esfera (7 pasos), su alcance y las correcciones pendientes. La secuencia anterior de diez pasos de esfera queda descartada como propuesta pedagógica.

## Estado y criterios
Material de estudio y revisión; no aprobación final de todas las ilustraciones. La esfera tiene defectos visuales pendientes: textura artificial, contornos excesivos y variación entre referencias. No convertirlos en tareas adicionales para el aprendiz.
Referencia a la izquierda para personas diestras; intercambiar paneles para zurdas sin espejar objeto ni iluminación. Mantener geometría, escala y luz. Guías punteadas se repasan una vez; velos tonales difusos permiten dibujar encima. Cada paso debe introducir una acción concreta, sin repetir instrucciones genéricas de contraste.
