## Reglas básicas

1. No alterar la geometría entre aplicaciones.
2. No usar color como único canal para comunicar estado o función.
3. Cuando una presencia represente un estado funcional, acompañarla con una alternativa textual programática.
4. No usar movimiento como condición necesaria para comprender un estado.
5. En Fase 3, diseñar `prefers-reduced-motion` como variante de primer nivel y mantener una versión estática equivalente.
6. No añadir partículas, estrellas, órbitas o signos mecánicos.
7. No usar la presencia para fingir una identidad humana; la interfaz debe informar textualmente de la interacción con IA cuando corresponda.
8. Si se publica una guía PDF, crear una versión accesible real; una lámina rasterizada no constituye por sí sola una guía accesible.
