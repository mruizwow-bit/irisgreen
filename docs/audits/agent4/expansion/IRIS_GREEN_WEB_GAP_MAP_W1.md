## Huecos confirmados

1. **Autonomía cotidiana no tiene bloque propio de juegos.** Hay juegos que rozan cocina, dinero, planificación o dispraxia, pero no una colección práctica para aprender tareas reales.
2. **No existe un recurso específico para aprender a atarse los cordones.**
3. **Vídeos:** el catálogo actual concentra cobertura en autismo, TDAH, TOC, ansiedad e identidad LGTBI+. No detecta cobertura temática explícita para dispraxia, sueño, discapacidad intelectual, altas capacidades, vida diaria/autonomía, empleo o relaciones.
4. **LGTBIQ+:** sí hay páginas informativas y 14 vídeos bajo «Identidad LGTBI+», pero falta una capa práctica conectada a nombre, pronombres, privacidad, límites y preparación de conversaciones.
5. **Rincón tranquilo:** ofrece mirar, escuchar y una pausa guiada; esa pausa marca un patrón fijo de inspiración/espiración. Falta una opción sin exigencia respiratoria.
6. **Pictogramas:** el conjunto actual ya permite construir apoyos para descanso, hambre, sed, baño, silencio, auriculares, sentarse, esperar y salir. La biblioteca local todavía no contiene equivalentes revisados para ayuda, dolor, ruido, luz, parar, no entiendo, repetir o necesito espacio.
7. **Navegación transversal:** disponer de páginas no garantiza que la persona encuentre el vídeo, juego o apoyo relacionado. La cobertura futura debe medirse también por enlaces entre formatos.

## Primer lote W1

W1 se centra en huecos reutilizables, no en producir muchas páginas iguales:

- hub de **autonomía cotidiana** con cuatro microjuegos;
- juego de **cordones paso a paso** con práctica sin cronómetro;
- tablero de necesidades con pictogramas Mulberry existentes;
- Rincón tranquilo con pausa de baja demanda;
- recurso LGTBIQ+ práctico;
- ampliación de videoteca en huecos verificados;
- enlaces cruzados desde los nuevos recursos.

## Alcance futuro

El objetivo de «todas las condiciones y situaciones con formatos útiles» es una línea de varias oleadas. No se creará un juego artificial para cada diagnóstico. La matriz se usará para priorizar cuándo vídeo, juego, rutina, imprimible o pictograma aporta utilidad real.
