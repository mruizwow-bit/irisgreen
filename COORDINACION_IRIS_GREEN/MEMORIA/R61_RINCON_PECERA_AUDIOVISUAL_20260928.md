## Decisión de María

La Pecera actual se acepta como donor visual para un piloto audiovisual del Rincón.

Cada escena futura tendrá su **propio sonido integrado**, exclusivo de esa escena.

No usar una biblioteca sonora genérica común para Pecera / Medusas / Mar / Río / Bosque.

## Piloto

Objetivo:
- ~10 min;
- vídeo + sonido propio;
- cámara fija;
- movimiento lento;
- low-stimulus;
- first-party;
- local;
- 0 autoplay.

Acción principal:
`Ver y escuchar`.

Controles:
- Silenciar / Activar sonido;
- Volumen;
- Parar;
- Pantalla completa.

Volumen inicial orientativo:
25–30 %.

## KEEP visual

- composición;
- peces;
- vegetación;
- piedras;
- burbujas;
- fondo azul;
- luz superior;
- estética ilustrada/volumétrica.

Refinar solo:
- profundidad;
- variación de trayectorias;
- plantas;
- caústicas;
- sombras.

## Método

Este piloto fija el método para futuras escenas.

No construir Medusas / Mar / Río / Bosque hasta HUMAN QA.
