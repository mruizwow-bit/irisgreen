# Reglas de uso · SABIK Visual Family Final V1

## Identidad

- Wordmark: SABIK T1.
- Sistema verbal: `SABIK` / `CLARIDAD INTELIGENTE.` / `Una IA que adapta la información para que sea más fácil de entender y usar.`
- Familia: `UNA MISMA ESENCIA · CUATRO PRESENCIAS`.

## Tamaños

- 64 px: recomendado.
- 40 px: recomendado.
- 32 px: mínimo recomendado para la presencia completa.
- 24 px: prueba de resistencia; no estándar.

## Fondos

Se autorizan blanco, gris muy claro y fondo oscuro siempre que la variante mantenga percepción suficiente. No rediseñar geometría para el fondo: usar el mismo master.

## Accesibilidad

La forma nunca será el único canal de un estado funcional. Añadir nombre/estado textual programático, respetar las preferencias del usuario y asegurar que la interfaz sigue siendo comprensible con color reducido, sin animación y con ampliación.

## Movimiento futuro

Solo movimiento con significado. Debe existir versión estática, opción reducida y comportamiento compatible con `prefers-reduced-motion`.
