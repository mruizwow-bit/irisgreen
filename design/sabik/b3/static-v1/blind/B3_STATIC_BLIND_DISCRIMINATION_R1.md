# B3_STATIC_BLIND_DISCRIMINATION_R1

## Objetivo

Comprobar diferenciación entre los cinco estados sin usar el nombre del estado como pista. No pretende demostrar todavía que una persona pueda inferir por sí sola el significado semántico.

## Material

Seis hojas independientes:

- Web · color;
- Web · monocromo;
- IA · color;
- IA · monocromo;
- Educa · color;
- Educa · monocromo.

Cada hoja muestra cinco imágenes a **64 px** y números 1–5. El orden está aleatorizado y no sigue PRESENTE → ORIENTAR → TRANSICIÓN → PAUSA → CONFIRMAR.

## Procedimiento

1. Mostrar una hoja sin la clave.
2. Pedir una opción entre: PRESENTE, ORIENTAR, TRANSICIÓN, PAUSA, CONFIRMAR.
3. Registrar selección y comentario de confusión.
4. No corregir ni modificar estados durante la misma ronda.
5. Completar la matriz de confusión solo después de cerrar la ronda.
