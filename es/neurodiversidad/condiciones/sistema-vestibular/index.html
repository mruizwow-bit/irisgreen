Sistema vestibular

proceso

Descripción

El movimiento, el mareo y buscar dar vueltas. Qué es el sistema vestibular, cuándo hay indicación clínica y por qué buscar movimiento no demuestra un trastorno.

Frecuencia e incertidumbre

No procede hablar de prevalencia como si fuera una enfermedad; se estudian diferencias de funcionamiento y sus efectos.

Qué ayuda

Rehabilitación vestibular cuando existe una indicación clínica y adaptaciones de seguridad o movimiento según necesidades.

Qué no está demostrado

Buscar o evitar movimiento no demuestra por sí solo un “trastorno vestibular” ni existe un ejercicio universal para regularlo.

Base documental
