## Por qué existe esta carpeta

Leer el repositorio y la coordinación canónica NO basta para ejercer bien un puesto.

Cada agente debe conocer:
1. qué profesión representa dentro del proyecto;
2. qué conocimientos profesionales necesita;
3. qué herramientas debe dominar;
4. cómo se aplican esos conocimientos a Iris Green;
5. qué evidencia demuestra que sabe ejecutar su trabajo;
6. qué debe enseñar al siguiente chat/agente.

Regla:

`IDENTIDAD → FORMACIÓN → PROYECTO → PRÁCTICA → EVIDENCIA → EJECUCIÓN → ENSEÑAR AL SIGUIENTE`

No:

`LEER GITHUB → INTENTAR → PEDIR A MARÍA QUE RESUELVA`

## Inicio obligatorio de un chat nuevo

Al abrir un chat/sesión nueva:

1. identificar alias + puesto en `EQUIPO_NOMBRES_PUESTOS.md`;
2. abrir esta carpeta `FORMACION/`;
3. leer la ficha de profesión propia;
4. leer el último `APRENDIZAJE_<ALIAS>_<FECHA>.md`, si existe;
5. estudiar fuentes externas necesarias para cualquier laguna detectada;
6. leer coordinación canónica viva: Estado, Control, Memoria, Orden vigente y Normativa aplicable;
7. ejecutar RESUME GATE sobre las ramas/sistemas que toque;
8. hacer una práctica corta de comprobación antes de modificar producto cuando el puesto sea de alto riesgo.

## Internet como universidad permanente

La formación NO se limita a los documentos internos.

Jerarquía recomendada:
1. documentación oficial del estándar/herramienta;
2. especificaciones y organismos técnicos;
3. documentación del proveedor;
4. libros/guías reconocidas;
5. cursos profesionales de entidades reputadas;
6. literatura académica cuando aplique;
7. fuentes comunitarias como contraste, nunca única autoridad en decisiones críticas.

Registrar:
- URL;
- título;
- versión/fecha cuando exista;
- qué se aprendió;
- cómo se probó en Iris Green.

## Leer ≠ dominar

Un agente no puede declarar “formado” porque haya leído documentación.

Cada bloque requiere:
- explicación propia;
- práctica;
- prueba/evidencia;
- error o caso negativo;
- runbook reutilizable.

## Handoff obligatorio de conocimiento

Antes de abandonar un chat cuando exista trabajo o aprendizaje material:

crear/actualizar:

`FORMACION/<AGENTE>/APRENDIZAJE_<ALIAS>_<FECHA>.md`

Debe permitir que el siguiente agente sea operativo sin repetir días de ensayo.

Plantilla:
`PLANTILLA_APRENDIZAJE.md`.

## Certificación interna

La formación del proyecto NO equivale a un título o certificación externa.

Un marcador interno significa únicamente:
- estudió;
- practicó;
- produjo evidencia;
- puede ejecutar ese alcance bajo las reglas de Iris Green.
