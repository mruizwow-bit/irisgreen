El taller

Videomapping

El videomapping (o mapping) proyecta luz sobre objetos para que parezcan cambiar de color, moverse o contar una historia. Aquí creas superficies, las llenas de contenidos y ajustas sus esquinas hasta que encajan con el objeto real.

Qué puedes crear aquí

  • Una caja de cartón que cambia de color
  • Una fachada o una maqueta con ventanas que se iluminan
  • Una escalera con escalones animados
  • Un espectáculo con tus imágenes o tus vídeos
  • Un archivo HTML para proyectarlo desde cualquier ordenador

Cómo se usa

  1. Elige un ejemplo o pulsa «Añadir superficie». Cada superficie es una forma de cuatro esquinas.
  2. Arrastra los círculos numerados para colocar las esquinas. Con el teclado: Tab hasta una esquina y flechas (Mayús para ir más rápido).
  3. En Propiedades elige el contenido: color, degradado, rayas, ondas, texto, una imagen o un vídeo de tu dispositivo.
  4. Conecta el proyector como segunda pantalla, lleva allí esta ventana y pulsa «Proyectar». Activa el «Patrón de ajuste» y mueve las esquinas hasta que encajen con el objeto.
  5. Guarda el proyecto y exporta el espectáculo en HTML para reproducirlo en otro momento.

Qué es el corner pinning

Un proyector casi nunca está justo delante del objeto, así que la imagen llega torcida. Ajustar las cuatro esquinas deforma la imagen con una transformación de perspectiva (homografía) para que, vista desde el objeto, quede recta. Es la misma técnica de los programas profesionales de mapping.

Cómo preparar una proyección

Busca una sala con poca luz. Coloca el objeto y el proyector fijos: si se mueven, hay que volver a ajustar. Las superficies claras y mates (cartón blanco, papel, paredes lisas) reflejan mejor la luz. Empieza con el patrón de ajuste: cada superficie muestra una rejilla y los números 1 a 4 en sus esquinas.

Sin destellos

Las animaciones de este estudio cambian el brillo como mucho una vez cada dos segundos, muy por debajo del límite de tres destellos por segundo que marcan las pautas de accesibilidad (WCAG 2.3.1). Si prefieres menos movimiento, las animaciones empiezan en pausa. Si usas tus propios vídeos, revisa que no tengan destellos rápidos.

Tus imágenes y vídeos

Las imágenes se reducen y se guardan dentro del archivo del proyecto. Los vídeos no caben en el proyecto: se reproducen desde tu dispositivo y hay que volver a elegirlos al abrir el proyecto o el espectáculo exportado. Nada se envía a internet.

Tu trabajo y tus archivos

Lo que haces se queda en esta pestaña del navegador. No se envía a ningún sitio y el taller no lo guarda en el navegador.

Para conservarlo, abre Archivo y pulsa «Guardar proyecto»: se descarga un archivo a tu dispositivo. Para seguir otro día, abre Archivo, pulsa «Abrir…» y elige ese archivo. Las exportaciones (imágenes, sonido, modelos 3D, juegos) también son archivos que descargas tú.
