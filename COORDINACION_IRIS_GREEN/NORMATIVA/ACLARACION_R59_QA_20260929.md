# R59 · aclaración QA · 29/09/2026

1. Una captura nombrada para una especie debe mostrar esa especie como selección activa. Si el nombre del archivo y la ficha activa no coinciden, la evidencia no acredita esa especie.

2. Si la coordinación canónica asigna un carril a un agente concreto, una entrega con un prefijo de rama distinto debe documentar quién ejecutó realmente el trabajo y por qué conserva ese nombre. El contenido técnico puede revisarse, pero la procedencia debe quedar reconciliada antes del gate final.
